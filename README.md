# e_commerce_app_demo

A demo e-commerece application with product listing, Category, cart and order listing

## Getting Started

how to run the project 

1. Clone project from git 
    -> git clone https://github.com/Lubluback/Machine-test-demo-E-Commerce-App
2. use flutter clean then  flutter pub get on terminal to downlaod dependency
3. Run Build runner to generate code
    -> flutter pub run build_runner watch --delete-conflicting-outputs
4. flutter run -> to run the project or start debugging for vs code

## Tools Used
1. Flutter & Dart
2. Provider -> for statemanagement
3. Dio -> for http client
4. Hive -> NoSQL Database
5. shared preference -> local key value store
